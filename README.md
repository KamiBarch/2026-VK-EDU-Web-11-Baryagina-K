# BEST FAQ
Gлатформа для вопросов и ответов (Q&A) для организации BEST Moscow. 
Позволяет пользователям задавать вопросы, публиковать ответы, голосовать за решения и управлять своим профилем.

## Инструкция по запуску

1. Склонируйте или скачайте репозиторий на свой компьютер.
2. Перейдите в папку `public/`.
3. Откройте файл `index.html` в веб-браузере.
4. Переходы между страницами работают через ссылки в интерфейсе.

## Список сверстаных страниц

* `index.html` — Главная страница со списком(лентой) вопросов.
* `question.html` — Cтраница вопроса, список ответов на него и форма добавления нового ответа.
* `ask.html` — Форма создания нового вопроса.
* `login.html` — Страница авторизации пользователя.
* `signup.html` — Страница регистрации нового аккаунта.
* `profile.html` — Страница настроек профиля (редактирование логина, почты и загрузка аватара).
* `base.html` — Базовый макет (header, боковая панель с тегами, footer).



## Инструкция по запуску для HW2

Запустить проект можно двумя способами, описанными ниже.

### Вариант 1 - Локальный запуск
1. Создайте и активируйте виртуальное окружение:
``
   python -m venv venv
   source venv/bin/activate  # Для macOS/Linux
   venv\Scripts\activate     # Для Windows
``
    Установите зависимости проекта:
``
    pip install -r requirements.txt
``
    Запустите локальный сервер:
``
    python manage.py runserver
``
    Проект будет доступен по адресу: http://127.0.0.1:8000/

### Вариант 2 - Запуск через Docker Compose
``
    Убедитесь, что у вас установлен Docker Desktop.
    Откройте терминал в папке с проектом и выполните команду сборки и запуска:
    
    docker compose up --build
``
    Проект будет доступен по адресу: http://localhost:8000/
